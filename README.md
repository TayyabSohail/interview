# Bike Bliss Landing Page with Weather API Integration

## Overview
This project replicates a landing page design from Figma using **Next.js**, **Tailwind CSS**, and **TypeScript**. It integrates **WeatherAPI** to show real-time weather data for a given city.

## Features
- **Responsive Design** (desktop view)
- **Weather API Integration**
- **Shadcn/UI** for UI components
- **TypeScript** for type safety
